## 变更范围

将原 `projects/remote/remote/bt_if/bt_cb.c` 的 BLE task、GAP、DISS、HOGPD callback trampoline 与四张 callback 表合入 `projects/remote/remote/tasks/task_btle.c`，并删除失去跨编译单元声明职责的 `bt_if/bt_cb.c` 与 `bt_if/bt_internal.h`。

## 实现边界

- `task_btle.c` 直接包含 `ble_drv.h`，为 `lsip_rf.reset()` 提供完整类型。
- callback trampoline、四张 callback 表、task/GAP handler、profile notify helper 与白名单 helper 收敛为文件私有 `static`。
- 使用文件内 `static` forward declarations 解决 callback 表与后续 handler 定义的声明顺序。
- `app_hid_rcv_data()` 保留文件作用域外部声明；`dis_profile_get_cb()` 保留 DISS callback 内局部外部声明。
- `task_btle.h` 公共 API 未改变。

## 保持不变的运行时语义

- 唯一 BT task、FreeRTOS queue、ls_ble dispatcher 和 transaction 所有权不变。
- dispatcher init、handler register、task pre-init/init、dispatcher start 的相对顺序不变。
- reset complete 仍进入 reset handler，再以原 GAP callback 表 enable GAP。
- GAP enable complete 后仍按 DISS、BASS、HOGPD、OTAS/OTA、GAP 配置、power-on 顺序初始化。
- `ble_task_execute()` 仍仅在 BT task 初始化后和每次队列消息处理后执行。
- `bt_stack_can_sleep()`、sleep/user schedule TODO 及低功耗裸接口问题未在本次修改。

## 静态验证

- 旧 `bt_cb.c` / `bt_internal.h` 引用清零。
- 四张 callback 表均为单一 `static const` 定义，并只在原注册位置使用。
- callback 和 handler 签名经独立复核与原实现一致。
- CMake/Make 继续通过目录 glob 纳入 `tasks/task_btle.c`，无需修改构建清单。
- `git diff --check` 通过。

本轮未构建、未测试；后续构建前需用户确认，并应重新配置 CMake 构建树以清除 glob 的旧生成依赖。
