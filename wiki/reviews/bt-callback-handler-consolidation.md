## 变更范围

在 `projects/remote/remote/tasks/task_btle.c` 内进一步收敛协议栈 callback 与此前跨文件 handler 形成的双层结构。callback 与业务实现已处于同一编译单元，因此删除仅做参数原样转发的中间函数，将业务逻辑直接放入协议栈 callback。

## 合并项

- reset complete callback 直接执行地址恢复、MAC 校验/生成、设置本地地址和 GAP enable。
- GAP enable complete callback 直接执行白名单/解析列表、DISS/BASS/HOGPD/OTAS/OTA 初始化、GAP 配置及 power-on。
- connection、disconnection、connection update、advertising report、activity start/stop、GAP event callback 直接承载原 handler 逻辑。
- bond callback 保留 16 位 status 拆分为 `info`/`value` 后直接执行原状态机。
- GAP info callback 直接处理 feature/version 查询与 PHY 切换。
- HOGPD notify complete callback 直接通知应用 observer。

## 保留的适配边界

- bond callback 必须保留协议栈 status 编码拆分。
- HOGPD notify callback 保留 `token` 参数并显式忽略。
- DISS callback 继续桥接外部 `dis_profile_get_cb()`。
- HOGPD write callback 继续桥接外部 `app_hid_rcv_data()`。
- BLE task sleep/can-sleep/user-schedule callback 及其 TODO 不在本轮处理。

## 保持不变的语义

- 四张 callback 表字段和协议栈函数指针签名不变。
- dispatcher init、handler register、task pre-init/init、dispatcher start 的相对顺序不变。
- 唯一 BT task、queue、dispatcher executor 与 transaction 所有权不变。
- `ble_task_execute()` 仍仅在 BT task 初始化后和每次队列事件后执行。
