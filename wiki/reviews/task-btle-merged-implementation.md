## 变更范围

- 将 `projects/remote/remote/bt_if/bt_app_if.c` 机械迁移为 `projects/remote/remote/tasks/task_btle.c`。
- 将 `bt_app_if.h`、`bt_types.h` 的宏、类型和公开 API 合入既有 `tasks/task_btle.h`。
- 删除旧 `bt_app_if.c`、`bt_app_if.h`、`bt_types.h`。
- 所有直接调用方统一改为包含 `task_btle.h`。
- `bt_common.h` 不再反向包含 `task_btle.h`；`bt_internal.h` 显式包含 `bt_common.h`，避免公共任务头与协议栈公共头形成循环。

## 保持不变的运行时语义

- 唯一 BT task 和 FreeRTOS queue 仍只有一份。
- `ls_ble_dispatch` transport、executor context、注册和启动顺序不变。
- ISR schedule、stack transaction、app transaction 仍进入同一队列。
- 跨任务 app transaction 的深拷贝、执行和释放规则不变。
- `ble_task_execute()` 仍只在 BT task 初始化后及每次队列消息处理后调用。
- `bt_app_*` 与 `app_ble_connected_state()` 等公开符号名称不变。

## 构建依赖

CMake 和 Make 已分别通配 `tasks/*.c` 并提供 `tasks` include 目录；删除 `bt_if/bt_app_if.c`、新增 `tasks/task_btle.c` 后无需修改构建清单。
