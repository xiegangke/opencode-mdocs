## 评估范围

静态评估将 `projects/remote/remote/bt_if/bt_cb.c` 的 BLE task、GAP、DISS、HOGPD callback trampoline 与 callback 表整合到 `projects/remote/remote/tasks/task_btle.c`。本轮不修改源码、不构建、不测试。

## 结论

技术上可行，且合并后 `bt_internal.h` 失去跨 translation unit 声明职责，可一并删除。合并不会天然改变唯一 BT executor、队列、dispatcher 或 transaction 语义，但必须保持 callback 表、handler 与初始化顺序。

## 当前调用边界

- `bt_stack_task_cb` 仅由 `ls_ble_task_pre_init()` 使用。
- `bt_stack_gap_cb` 仅由 `ls_ble_gap_enable()` 使用。
- DISS/HOGPD callback 表仅由对应 profile 初始化使用。
- task/GAP trampoline 只由 callback 表引用。
- `bt_internal.h` 只被 `bt_cb.c` 与 `task_btle.c` 包含。
- `dis_profile_get_cb()` 和 `app_hid_rcv_data()` 是合并文件之外的实现，必须保留外部链接及精确声明；后者按工程配置存在不同候选实现。

## 推荐实施策略

优先分两步降低回归面：

1. 机械搬入 `bt_cb.c` 内容，加入 `ble_drv.h`，保留函数体、签名、callback 表字段和初始化顺序；删除 `bt_cb.c`，以文件内前置声明替代 `bt_internal.h` 后删除该头。
2. 静态确认无仓内外部使用后，再将 trampoline、四张 callback 表、task/GAP handler、`bt_app_profile_notify_complete()` 和仅内部使用的白名单辅助函数私有化为 `static`。

如果一次完成，也必须按同一符号清单逐项核查。不要把私有 callback/handler 放进 `task_btle.h`。

## 必须保持的顺序

- dispatcher init；task/GAP/GATT handler 注册；`ls_ble_task_pre_init(&bt_stack_task_cb)`；`ls_ble_task_init()`；dispatcher start。
- reset complete 进入 reset handler，再以 `bt_stack_gap_cb` enable GAP。
- GAP enable complete 后依次初始化 DISS、BASS、HOGPD、OTAS、flash/OTA，再配置 GAP 参数并进入 power-on 流程。
- `ble_task_execute()` 仍只在唯一 BT task 初始化后和每次队列消息处理后执行。

## 依赖与构建

`task_btle.c` 已包含 `sdk_config.h`、`ls_ble_gap.h`、`ls_ble_task.h`、DISS/HOGPD 类型头；合并时只需补充 `ble_drv.h` 以完整解析 `lsip_rf.reset()`。CMake 与 Make 均通配 `bt_if/*.c` 和 `tasks/*.c`，删除 `bt_cb.c` 无需改源文件清单；CMake glob 未使用 `CONFIGURE_DEPENDS`，验证时应显式重新配置，避免旧生成文件继续引用删除文件。

## 风险

- 中：移动时改变 callback 签名、表字段或初始化相对顺序。
- 中：误将外部 `dis_profile_get_cb()` / `app_hid_rcv_data()` 私有化或丢失声明。
- 低：include 去重、`bt_internal.h` 删除和私有符号 static 化。
- 既有高风险但不属于本次：`bt_stack_can_sleep()` 无条件返回可睡眠，sleep/user schedule 仍为 TODO，低功耗路径仍裸调用 `ble_task_sleep/init`；不得在文件合并时顺手修改。

## 验证标准

静态确认旧文件/头引用为零，四张 callback 表单一定义，trampoline/handler 无外部引用，初始化调用顺序不变，`ble_task_execute()` 仍只有 BT task 内两处。经用户确认后重新配置并执行 CMake 与 Make 构建，再验证 reset、GAP enable、广播、连接/断开、配对、DISS、HOGPD、OTA callback 行为。
